# Buyer notes — CableCheck

Thanks! Your purchase = access to this repository (automatic GitHub invite
from Polar — check your email; if the invite never lands, reply with your
GitHub username to snailmail3d@gmail.com).

## Start here

1. Get the board: search **"ESP32-C3 0.42 OLED Mini"** (board marking
   HW-675) on AliExpress or Amazon — about $6–8 shipped.
2. Flash `firmware/cablecheck.ino` (README has exact commands).
3. Plug random cables into it and enjoy knowing.

## What's in the box
